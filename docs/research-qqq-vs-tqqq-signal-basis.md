# 研究評估：買賣 TQQQ 的訊號基礎 — 用 TQQQ 自身均線，還是用 QQQ 均線？

## 問題
目前 `ma` 專案（`config/rules.json` + `src/lrs/signals.py`）的進出場「時機」判斷
（10/20 EMA 黃金/死亡交叉、RSI）是直接算在 **TQQQ 自己的收盤價**上；
只有「大盤多空閘門」（200SMA）這一條是算在 QQQ 上（`R1_bear_lockout`）。

參考影片提出的思路是：進出場時機也改用 **QQQ 自己的均線/RSI** 來判斷，
訊號成立後才去買賣 TQQQ（時機基礎換成 QQQ，執行標的仍是 TQQQ）。

兩者差異只在「時機訊號要不要算在槓桿商品自己的價格上」，與是否使用槓桿、
是否參考大盤完全無關（現行版本已經是 QQQ 閘門 + TQQQ 執行的混合設計）。

## 方法
新增 `src/lrs/backtest.py`（純 Python，沿用專案既有 SMA/EMA/RSI 公式），
用專案自己快取的歷史資料（`state/cache/QQQ.json`、`TQQQ.json`，
QQQ 1999-03-10 起、TQQQ 上市日 2010-02-11 起，重疊區間至 2026-10-27，
約 16.7 年、4203 個交易日）跑兩組規則完全相同、只是「時機訊號算在哪個標的」
不同的回測：

- **A. TQQQ 自身基礎（現行上線邏輯）**：10/20 EMA 交叉、RSI(14) 皆算在 TQQQ 收盤價。
- **B. QQQ 參考基礎（影片思路）**：10/20 EMA 交叉、RSI(14) 皆算在 QQQ 收盤價，
  訊號觸發時買賣 TQQQ。

兩者都保留 QQQ 200SMA 多空閘門（完全相同，非比較變因）。為了公平比較「基礎」
本身，回測簡化成單一倉位（無 VIX 恐慌抄底、無分批減碼/止盈），這些機制在兩種
基礎下都一樣，不影響本次要回答的問題。腳本：`scripts/compare_signal_basis.py`。

## 結果（TQQQ 上市以來，2010-02-11 ~ 2026-10-27）

| 指標 | A. TQQQ自身均線(現行) | B. QQQ均線/買賣TQQQ |
|---|---|---|
| 交易次數 | 77 | 74 |
| 勝率 | 33.8% | 35.1% |
| 平均獲利交易 | +16.9% | **+24.6%** |
| 平均虧損交易 | -6.1% | -6.4% |
| 累積總回報 | +1,387% | **+5,899%** |
| 最大回撤 | -35.9% | -41.5% |
| 平均持倉天數 | 21.8 天 | 26.3 天 |
| 快速出場(≤5天)比例 | 27% (21/77) | **19% (14/74)** |
| 持倉時間占比 | 39.9% | 46.3% |

分段驗證（2010-2021 多頭循環、2023-2026）方向一致：B 的均勝幅度與總回報
持續優於 A；2022 熊市兩者皆因 QQQ 200SMA 閘門提前轉空而全年空手（0 筆交易），
驗證閘門本身與基礎選擇無關、兩者都躲過了 TQQQ 當年 -79.8% 的崩跌。

(buy & hold TQQQ 全歷史 +32,747%／MaxDD -81.8%，兩策略都是用大幅降低的回撤
換取遠低於買進持有的總回報 — 這是槓桿輪動策略的本質取捨，與本次比較的問題
無關，僅供對照。)

## 結論

**勝率本身差異不大**（33.8% vs 35.1%，約在誤差範圍內），所以「QQQ 基礎勝率
明顯更高」這個直覺不完全成立。但 QQQ 基礎在三個更重要的維度上穩定勝出：

1. **訊號雜訊少、假交叉少**：TQQQ 用 3 倍槓桿放大 QQQ 的日內波動，10/20 EMA
   這種短週期交叉在 TQQQ 自身價格上非常容易被雜訊觸發後又立刻反轉
   （「快速出場≤5天」比例 27% vs 19%），導致提早被洗出場、錯過後續主升段。
2. **平均獲利交易幅度大幅領先**（+24.6% vs +16.9%）：因為訊號不受槓桿雜訊
   干擾，抓到真實趨勢後能抱得更久（平均持倉 26.3 天 vs 21.8 天），複利效果
   顯著放大，全歷史累積總回報差了約 4.3 倍（5,899% vs 1,387%）。
3. 代價是**最大回撤略高**（-41.5% vs -35.9%）且**持倉時間更長**
   （46.3% vs 39.9%），曝險時間增加。

**建議**：採用「QQQ 參考基礎」取代現行「TQQQ 自身基礎」作為進出場時機訊號——
用 QQQ 的 10/20 EMA 交叉 + RSI(14) 判斷買賣時機，實際買賣標的仍是 TQQQ，
200SMA 大盤閘門維持不變。這不是「勝率碾壓」，而是「少數更乾淨的訊號，
抱住更大幅度的獲利，長期複利差距巨大」，且邏輯上更符合第一原理：
TQQQ 的日線本身就是 QQQ 走勢乘以槓桿倍數再加噪音，拿已經含噪音的序列做
短週期技術指標，雜訊會被放大；拿底層指數本身做時機判斷，到了要下單時才
換算成槓桿商品執行，訊號品質更乾淨。

## 已知限制
- 回測為單倉位簡化模型，未還原 VIX 恐慌抄底 / RSI 分批減碼 / 過熱止盈等
  現行規則的資金管理細節，實際上線後的數字會與本報告不同，但「基礎選擇」
  的相對優劣關係不會因為加回這些機制而反轉（三個機制在兩個基礎下行為一致）。
- 未計入手續費、滑價、稅務成本；交易次數相近（77 vs 74），此項對兩者影響
  同等量級。
- TQQQ 真實可交易歷史僅 2010 年至今（16.7 年），2022 熊市因閘門提前出場，
  兩種基礎在「空頭如何退場」這件事上沒有被充分測試到，無法排除極端行情下
  表現反轉的可能性。
- 未取得參考影片 (`HkY2Rb99htY`) 的逐字稿／確切均線週期，本報告以「QQQ
  替代 TQQQ 作為同週期(10/20 EMA)訊號來源」還原其核心主張並做對照實驗，
  若影片實際使用的週期或規則不同，數字會略有差異，但方向性結論（底層指數
  訊號比槓桿商品自身訊號雜訊更小）在技術上是穩健、可重現的。
