# 現金 / QQQ / TQQQ 三資產配置：財富種植園策略移植

[MAM-6] 任務：依據使用者提供之 YouTube《TQQQ 長期持有策略：10年50倍策略詳解》（頻道「財富種植園」）完整逐字稿，將其量化資產配置與動態切換策略深度融合進本專案。

## 1. 逐字稿策略核心架構

依據逐字稿內容，策略將總資金拆為兩部分，全部操作以 QQQ（納指100 ETF）之技術走勢為發令槍：

1. **10% 底倉（現金 / SGOV 國債）**：
   - 死守不動：除非 QQQ 從歷史高點回落超過 30%（黃金坑），否則絕對不准動用此 10% 現金。
2. **90% 機動倉（QQQ / TQQQ / 現金動態切換）**：
   - 每日收盤檢查 QQQ 的三大核心數據：
     - (a) **收盤價 vs 200日均線**：多空分水嶺。
     - (b) **距離歷史最高點 (ATH) 回落幅度**：牛市回檔、危險區、半山腰拉扯區、黃金坑判定。
     - (c) **20日均線位置與斜率**：短線進出與防假反彈濾網。

### 多空狀態與機動倉對應表

| 大盤狀態 | 觸發條件 (QQQ 基礎) | 機動倉 (90%) 動作 | 總配置目標 (含10%底倉現金) |
|---|---|---|---|
| **牛市常態** | QQQ > 200MA，且高點回落 ≤ 10% | 45% QQQ + 45% TQQQ（市值偏差>20%調頻） | 現金 10% / QQQ 45% / TQQQ 45% |
| **牛市逢低進攻** | QQQ > 200MA，且高點回落 > 10% | 機動倉全轉 TQQQ 逢低進攻 | 現金 10% / QQQ 0% / TQQQ 90% |
| **高位出貨避險** | 距歷史高點 ≤ 5%，當日成交量 ≥ 65日均量2倍且收黑K | 立刻將機動倉 90% 換成 QQQ 鎖定獲利 | 現金 10% / QQQ 90% / TQQQ 0% |
| **空頭初期危險區** | QQQ < 200MA，且回落 < 10% | 比較危險，機動倉全部賣出換現金 | 現金 100% / QQQ 0% / TQQQ 0% |
| **空頭半山腰拉扯** | QQQ < 200MA，回落介於 10% ~ 30% | 價格站上 20MA → 買進 TQQQ；跌破 20MA → 防守持現金 | 站上：10%現金/90%TQQQ；跌破：100%現金 |
| **空頭黃金坑抄底** | QQQ 回落 > 30%（不論均線） | 鐵定黃金坑，無視任何訊號全倉抄底 TQQQ | 現金 10% / QQQ 0% / TQQQ 90% |

### 兩大紀律鐵律

1. **鐵律一：今天賣，明天買**
   - 觸發賣出（降低曝險）時當日執行賣出；但若需要買入加碼（提升 TQQQ/QQQ 曝險），當日不追買、資金暫存現金，必須隔日確認訊號持續才買進，避免盤中或單日雜訊追高。
2. **鐵律二：防假反彈**
   - 當前處於防守狀態（持全現金或全QQQ，機動倉TQQQ=0）時，若訊號轉為買進TQQQ，必須同時滿足：
     - (1) **在防守狀態已至少維持 2 個交易日**。
     - (2) **短線 20 日均線斜率明確向上掉頭**。
   - 若不滿足上述條件，忽略買入訊號，繼續維持原防守倉位觀望。

## 2. 專案參數假設與可調設定

逐字稿中有少數細節未明確定義數值公式，本專案將其轉為透明可調的參數，配置於 `config/settings.json` 的 `allocation` 區塊：

- `thresholds.bull_dip_pct`: 10（牛市回檔進入進攻模式的門檻 %）
- `thresholds.bear_defensive_pct`: 10（跌破200MA危險防守區的門檻 %）
- `thresholds.golden_pit_pct`: 30（黃金坑抄底門檻 %）
- `thresholds.near_ath_pct`: 5（高位出貨訊號判定的距高點幅度 %）
- `thresholds.vol_spike_multiple`: 2（出貨巨量倍數，相對於均量）
- `thresholds.vol_avg_window`: 65（成交量均線天數）
- `thresholds.ma20_window`: 20（短線均線天數）
- `thresholds.ma20_slope_lookback`: 3（判定20MA斜率向上的回溯天數）
- `thresholds.defensive_min_days`: 2（防假反彈最短防守天數）

## 3. 持倉快照與再平衡

使用者持倉記錄於 `state/allocation_snapshot.json`（已加入 `.gitignore`）。
例如使用者當前持倉：

- `QQQ`: $22,928
- `SGOV` (現金等價物): $2,314

系統在每次執行 `python3 main.py` 時，會自動比對當前「策略目標權重」與「實際持倉權重」：
- 若偏離超過 `allocation.drift_threshold_pct`（預設 ±5%），即在終端機與 HTML 圖表報告中發出明確的再平衡警示與具體調倉建議。
